# Customize the UI

Themes, docks, and About.

## Themes

Use the **View** menu (or theme controls) to switch **Default**, **Light**, or **Dark**.

**Screenshot:** Theme selection

![Theme menu](images/ss-theme-menu.png)

## Panels

Toggle visibility of **Plans**, **Properties**, **Sliders**, and **Zoom**. Use **Reset Panels** if the layout feels lost. Docks inside the Plan Diagram tab can be rearranged within that tab.

**Screenshot:** View menu panel toggles

![View panels](images/ss-view-panels.png)

<!-- Drop file at docs/user/images/ss-view-panels.png -->

## About and exit

- **Help → About** — version, repository, and issues links.
- **File → Exit** — **Ctrl+Q** / **Cmd+Q**.
