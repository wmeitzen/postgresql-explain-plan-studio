# Managing plans

Organize plans in the **Plans** tree: folders, drag-and-drop, sort, and document settings.

## Toolbar

- **Add Plan** — new plan document.
- **Add Folder** — group plans.
- **Delete** — remove the selection (confirm when prompted).
- **Duplicate** — copy a plan.
- **Settings** — tree order and grouping.

## Context menu and drag-and-drop

Right-click a plan or folder for the same actions, plus **Compare Plans** and **Sort Now A→Z / Z→A**. Drag plans into folders (or reorder when Manual order is enabled).

**Screenshot:** Plans tree with folders

![Plans tree folders](images/ss-plans-tree-folders.png)

## Settings

Open **Settings** on the Plans toolbar to choose:

- **Order** — by name or manual.
- **Name order** — A→Z or Z→A when ordering by name.
- **Grouping** — how plans are grouped in the tree.
